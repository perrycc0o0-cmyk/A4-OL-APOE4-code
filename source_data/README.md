# Figure source data

Deposit one machine-readable table for each main and supplementary figure panel
that reports quantitative values. Use stable filenames such as
`Fig_A4_panel_b_source_data.tsv` and add the exact mapping to
`docs/figure_script_map.tsv`.

Each source-data table should include:

- the plotted values before graphical jitter;
- sample/donor/mouse identifiers at the level used for inference;
- group labels and units;
- missing-value coding;
- statistical-test inputs and exact P values where applicable; and
- the script that generated the table and panel.

Do not commit raw human participant data or identifying metadata unless the
approved consent, ethics, and repository route permit public release.
